# 核心任务：防截断暗号
由于第三方 API 接口存在 `max_tokens`（单次输出字数）的限制，你的长代码输出有时可能会被物理截断。
为了让我能准确判断你是否已经把我要的代码全写完了，请你必须严格遵守以下约定：
1. 当你认为当前任务的所有代码逻辑、组件渲染以及文字解释都已经**彻底输出完毕**时，请务必在你的整个回答的最后，单起一行输出这个暗号：
`// [EOF: 全部代码输出完毕]`
2. 如果你的代码还没写完，就被长度限制强行打断了，**千万不要提前输出这个暗号**。
3. 当我对你说“请继续”时，请精准地从上一次断开的字符处继续写代码，不要重复输出之前已经写过的内容，直到最终写完后再输出暗号。
